TRANSMIT (TX) WARNING
Before enabling transmit (TX), check the radio rules for your country,
state/province and local area. Use permitted frequencies, power, mode and
antenna settings and obtain any required licence or authorization.
You are responsible for lawful operation; this experimental firmware does
not guarantee regulatory compliance.

This package is for HackRF One + PortaPack H4M. Do not use its BIN for
HackRF Pro or PortaRF. Source, version and upstream revision are recorded
in SOURCE-COMMIT.txt, FIRMWARE-VERSION.txt and UPSTREAM-COMMIT.txt.
It has not been flashed or physically tested by the automated build.

SD UPDATE (when you choose to test it)
1. Back up your SD card and extract the downloaded Actions ZIP once.
2. Copy the contents of SD_CARD onto the SD root, merging folders and
   replacing matching files while keeping your personal files/settings.
3. Keep H4M_PORTAMESHRF.ppfw.tar intact inside FIRMWARE. Do not extract it
   or substitute the raw BIN for this SD update procedure.
4. Open Utilities > Flash Utility, select H4M_PORTAMESHRF.ppfw.tar and
   wait for completion. Do not interrupt power.
5. Restart and compare About with FIRMWARE-VERSION.txt. Use the matching
   APPS and BASEBAND from this package; mixed builds can fail to load.
6. Open Transceiver > PortaMeshRF or Auto Repeater. See PORTAMESHRF.md
   for channels, key import, encryption and direct messages.

WINDOWS USB ALTERNATIVE
Copy the matching SD files first. Connect a USB data cable and select
HackRF mode on the PortaPack. Open USB_FLASH_WINDOWS and run
mayhem_flasher.bat. Choose device 1 (HackRF One / PortaPack), then action
1 (Flash Mayhem firmware). That uses firmware/firmware_hackrf.bin, which
is byte-identical to SD_CARD/FIRMWARE/PortaMeshRF.bin.
This candidate includes the upstream Windows script, utilities and driver.
The other device/DFU/factory choices require separate official firmware
files which are not included in this H4M candidate. Do not select them.

LINUX / MAC USB ALTERNATIVE
Install HackRF host tools, select HackRF mode, then run:
  hackrf_spiflash -w SD_CARD/FIRMWARE/PortaMeshRF.bin
Restart after successful flashing and check the recorded version.

CHECKSUMS AND TESTING
SHA256SUMS.txt covers the update TAR and both copies of the firmware BIN.
The build validates the exact 1 MiB checksum/version, app compatibility,
resident updater, memory/layout and USTAR archive. These are software
checks, not proof of RF delivery or on-device reliability. Start with short
All/broadcast messages in both directions before trying encrypted DMs.
